# GridLock

A ShellHacks 2026 proof of concept for exploring utility planning records and cross-company proximity.

This is a separate project from the Metal portal experiment. Implementation begins during the current event. The supplied workbook remains the original-data baseline; reviewed corrections are annotations, not replacements.

Sperry's clarification permits representative center points, an adjustable 25-mile threshold, and historical supplied records. Scenarios or models must distinguish planned milestones from actual construction and may not claim unvalidated probabilities.
